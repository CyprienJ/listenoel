{% trans "Quick Add privacy policy" %}

{% trans "Last updated: 8 July 2026" %}

{% trans "Data handled by the extension" %}

{% blocktrans trimmed %}Quick Add reads the active shop page only after you click its toolbar button and grant access to that shop. It extracts candidate product titles, URLs, images, prices, currencies, and product metadata.{% endblocktrans %}

{% blocktrans trimmed %}Extraction and review happen locally in Firefox. Product information is sent to nosCadeaux only after you click “Add to my list.” Pages that you scan but do not add are not sent to nosCadeaux.{% endblocktrans %}

{% trans "Account connection" %}

{% blocktrans trimmed %}The extension uses an authorization code and a scoped access token to connect to your nosCadeaux account. It never receives or stores your password. The token is stored in Firefox extension storage; the server stores only its cryptographic hash.{% endblocktrans %}

{% trans "Purpose and retention" %}

{% blocktrans trimmed %}Submitted product information is stored as a gift in your nosCadeaux account and remains there until you edit or delete it. You can revoke the extension token with the Disconnect button. Temporary authorization codes expire after five minutes and cannot be reused.{% endblocktrans %}

{% trans "Sharing" %}

{% blocktrans trimmed %}Quick Add does not sell product or browsing data and does not use it for advertising. Product data is shared through nosCadeaux only according to the gift-list and group visibility settings you select.{% endblocktrans %}

{% trans "Permissions" %}

{% blocktrans trimmed %}Access to shop pages is requested one shop at a time. You can review or revoke these permissions in Firefox’s Add-ons Manager. Disconnecting removes the extension’s local account token and revokes it on the nosCadeaux server when reachable.{% endblocktrans %}
